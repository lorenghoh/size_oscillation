# GP Modelling for Cloud Size Distribution

This repository consists of codes accompanying the paper _Quantifying the Oscillatory Evolution of Simulated Boundary-Layer Cloud Fields Using Gaussian Process Regression_ by [Oh and Austin, 2024](https://doi.org/10.5194/egusphere-2024-352).

The Jupyter notebooks can be seen at:

> https://lorenghoh.github.io/size_oscillation

which is a website built with Jupyter Book 2 (based on MyST Markdown).
