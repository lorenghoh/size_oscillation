# GP Modelling for Cloud Size Distribution

## About This Book

This webpage provides a collection of Jupyter notebooks accompanying the paper _Quantifying the Oscillatory Evolution of Simulated Boundary-Layer Cloud Fields Using Gaussian Process Regression_ by [Oh and Austin, 2024](https://doi.org/10.5194/egusphere-2024-352) showing the numerical steps taken to obtain the results presented in the paper.

The full Github repository can be found [here](https://github.com/lorenghoh/size_oscillation), which also includes a set of Python scripts, mainly used to pre-process the three-dimensional output fields from the high-resolution large-eddy simulation. Most of the notebooks focus on using the Gaussian Process (GP) model to quantify the oscillatory behaviour in the slope of the cloud size distribution.

:::{aside}
These scripts are mainly used for the regression tasks that makes use of Decision Tree algorithm and robust linear regression.
:::
